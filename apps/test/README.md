# Apps: Test

This folder contains a few applications related to testing and development.

A place to run tests and test things out.

- **test-client**: Contains the integration tests run by vscode-e2e-runner. All integration tests are just TypeScript with a basic wrapper.

- **test-server**: An app used for testing the tokenizer and creating our automated tests.

- **vscode-e2e-runner**: Basic application that runs our VSCode integration tests which are located in `test-client`.
